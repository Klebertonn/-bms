BMS Firmware

Guia de execução local para simulação do firmware

Este guia mostra como compilar e executar o firmware em modo simulado no PC, sem hardware físico, e também como abrir o dashboard local com dados simulados.

1. Pré-requisitos

  • VS Code
  • Extensão PlatformIO IDE
  • Git instalado no sistema
  • Terminal PowerShell ou CMD
cd "C:\Users\Klebe\OneDrive\Desktop\bmsfc"

2. Compilar em modo simulado

O ambiente native executa a lógica do firmware em mock/simulação no computador.

pio run -e native

3. Executar a simulação do BMS + dashboard web

Para iniciar o firmware e abrir o painel web em paralelo, use o script local de execução simultânea.

powershell -ExecutionPolicy Bypass -File .\scripts\start_bms_simulation.ps1

Esse fluxo abre ao mesmo tempo:

  • o BMS em ambiente native
  • o dashboard em web/index.html

Se quiser rodar apenas o firmware em console:

.\.pio\build\native\program.exe

4. Executar testes

Valide a simulação com a suíte de testes nativos.

pio test -e native

5. Abrir o dashboard local

O dashboard demo usa dados simulados e não precisa de ESP32.

web\index.html

Você pode abrir este arquivo diretamente no navegador ou usar a opção Open with Default Browser no VS Code.

5. Fluxo rápido de uso

cd "C:\Users\Klebe\OneDrive\Desktop\bmsfc"
pio run -e native
pio test -e native
Start "web\index.html"
Observação: o ambiente native foi configurado para simulação no PC. Ele é o caminho recomendado para testar a lógica do firmware sem hardware real e para validar comportamentos antes de gravar o firmware na placa ESP32.

6. Verificação de sucesso

  • Build do projeto concluído com sucesso
  • Teste nativo executado sem falhas
  • Dashboard carregando em navegador
  • Firmware em simulação funcionando corretamente
