Guia de execucao local e instalacao no ESP32

Procedimento para demonstrar o BMS no PC, gravar o firmware e preparar uma bancada inicial.

Atencao: o projeto esta configurado para PACK_CELL_COUNT = 3, um pack 3S. Nao conecte uma unica celula diretamente sem ajustar a configuracao e validar o circuito de medicao.

1. Pre-requisitos

  • VS Code com a extensao PlatformIO IDE.
  • Cabo USB de dados e placa ESP32 compativel com esp32dev.
  • Driver USB instalado, caso o Windows nao reconheca a porta COM.
cd "C:\Users\Klebe\OneDrive\Desktop\BMSPC2\-bms"

2. Rodar no PC

O ambiente native executa a logica em modo simulado, sem hardware fisico.

pio run -e native
pio test -e native

Ultimo resultado validado: 34 testes aprovados e 0 falhas.

3. Abrir o dashboard

Abra web/index.html no navegador. O modo demo usa dados simulados e nao exige o ESP32.

4. Compilar para o ESP32

Com a bateria desconectada, compile o firmware:

pio run -e esp32dev

O ambiente usa Arduino, INA219, MAX17048, OLED SSD1306, CAN TWAI e BLE.

5. Gravar e monitorar

  1. Conecte o ESP32 ao PC por USB.
  2. Confirme a porta COM no PlatformIO.
  3. Execute:
pio run -e esp32dev -t upload
pio device monitor -b 115200

Se o upload ficar aguardando, mantenha BOOT pressionado no inicio e solte quando a gravacao comecar.

6. Confirmar o boot

Reinicie a placa com o monitor aberto. Procure mensagens de boot, deteccao dos perifericos e [BMS] READY. Uma mensagem FAIL indica que o periferico nao foi detectado e deve ser investigado antes do teste com bateria.

7. Ordem da bancada

  1. Grave e teste o ESP32 sem bateria.
  2. Valide INA219, OLED, MAX17048 e NTC.
  3. Confirme que os MOSFETs iniciam desligados.
  4. Use fonte de laboratorio com limite de corrente e fusivel.
  5. Meça as tensoes com multimetro antes de habilitar carga ou descarga.
  6. Avance para uma celula ou pack de teste protegido apenas depois dessas verificacoes.

8. Seguranca eletrica

  • Nunca ligue uma celula de litio diretamente a um GPIO do ESP32.
  • O ADC atual usa SCALE_FACTOR = 1.0f; uma celula de 4,2 V pode exceder a faixa segura do ADC.
  • Use divisor de tensao ou circuito dedicado de monitoramento validado com multimetro.
  • Para uma unica celula, ajuste PACK_CELL_COUNT, limites, SOC e mapeamento do ADC antes do teste.
  • Nao carregue a celula sem carregador apropriado e supervisao.

Checklist

  • ☐ Testes nativos passaram
  • ☐ Dashboard abriu
  • ☐ Firmware ESP32 compilou e foi gravado
  • ☐ Boot serial confirmado em 115200
  • ☐ Sensores detectados
  • ☐ ADC, divisor e MOSFETs validados
  • ☐ Fonte limitada e fusivel instalados
Avance para packs reais somente depois de validar todos os itens de hardware e seguranca.
