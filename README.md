# BMS

Repositório do projeto **BMS** (Battery Management System).

## Estrutura
- `docs/` — requisitos, arquitetura, hardware e documentação de suporte
- `include/` — cabeçalhos de interfaces
- `src/` — implementação
- `lib/` — bibliotecas externas/auxiliares
- `test/` — testes

## Build / Dev
O projeto usa **PlatformIO** (ver `platformio.ini`).
